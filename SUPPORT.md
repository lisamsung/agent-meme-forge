# Support

For installation and usage questions, start with the
[README](README.md), the [Chinese README](README.zh-CN.md), and the
[skill workflow](skills/generate-meme-gif-pack/SKILL.md).

Use [GitHub Discussions](https://github.com/lisamsung/agent-meme-forge/discussions)
for setup questions, workflow advice, and examples. Use the issue tracker only
for reproducible bugs and scoped feature requests.

This is a maintainer-supported open-source project without a guaranteed response
time. When asking for help, include the release or commit, operating system,
Python version, command, and sanitized error output. Do not post API keys,
signed URLs, or private reference portraits.

Security reports belong in the private channel described in
[SECURITY.md](SECURITY.md).
