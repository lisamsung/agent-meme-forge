Codex Skill · WeChat GIF Sticker Pack

agent-meme-forge

从参考图或纯文字角色概念生成一套真的会被发送的动态表情包。先规划角色卡和 1x4 motion-sheet 提示词，再输出默认 24 个适配微信表情开放平台的 GIF。

GitHub 中文文档

梗优先

每个表情都要有明确聊天场景：催进度、假装听懂、组会渡劫、生产别碰、早八索命。

风格化本人

保留发型、脸型、气质和标志特征，但避免高仿真人换脸，更适合公开发布。

微信打包

同时输出人类可读 GIF 名和微信上传所需的数字文件、缩略图、封面、图标、横幅。

主动生图

支持 text_concept 直接起角色，自动写 24 条无文字 1x4 动作 sheet 提示词，再统一加中文梗。

真实帧动画

迁移 sprite sheet 规则：精确网格、同尺度、同包围盒、不出格，processor 按真实帧生成 GIF。

AI Mascot Sample

当前推荐链路会先用 text_concept 生成原创 AI 吉祥物的 1x4 motion-sheet 提示词， 再调用 image_gen 为每个表情产出真实动作帧， 之后由本地脚本切图、加中文梗、压成微信规格 GIF。

视觉形象可以参考熟悉的暖色 AI 助手气质，但输出要求是原创角色，不使用官方 logo 或品牌标识。

Quick Start

python3 -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
python skills/generate-meme-gif-pack/scripts/meme_pack.py plan-pack \
  --subject "warm geometric AI assistant mascot with cream body and coral accents, original character, no official logo" \
  --persona 科研打工人 \
  --style clean-sticker \
  --pack-size 24 \
  --mode wechat \
  --animation-layout 1x4 \
  --output output/ai-research-plan.json

# Use the plan's image_prompts with Codex image_gen, save accepted 1x4 sheets to raw-frames/.
# Static 4x6 contact sheets are preview-only. If image_gen returns one:
python skills/generate-meme-gif-pack/scripts/meme_pack.py split-sheet \
  --input output/raw-sheets/ai-research-sheet.png \
  --output-dir raw-frames \
  --rows 6 \
  --cols 4

python skills/generate-meme-gif-pack/scripts/meme_pack.py build-pack \
  --source-dir raw-frames \
  --output-dir output/my-pack \
  --persona 科研打工人 \
  --style clean-sticker \
  --pack-size 24 \
  --mode wechat \
  --source-layout 1x4
