# Personas

Personas determine the default joke pool and props. They are not rigid audiences; mix in common reactions so the pack is useful beyond one niche.

## 科研打工人 / 研究僧

Themes: papers, literature review, lab work, supervisor messages, group meeting, revision, significance, graduation anxiety.

Good sends: “文献又长出来了”, “组会渡劫中”, “显著吗不显著”, “返修意见比正文长”.

## 码农

Themes: bug, production, compile, deploy, logs, restart, requirement changes, code that barely works.
