# Meme Library

The default pack composition is 12 common chat reactions, 8 persona-specific reactions, and 4 reusable fillers. Replace weak items before generating; do not ship decorative stickers without a send scenario.

## Common High-Frequency Reactions

- 收到离线: “收到 / 但灵魂已离线” for acknowledging messages while mentally gone.
- 加载中: “别催 / 我在加载” for delays.
- 先装懂: “我先 / 装懂一下” for pretending to understand.
- 合理吗: “这合理吗” for absurd requests.
- 在写了: “我在写了 / 真的” for progress pressure.
- 已读乱回: “已读 / 但乱回” for low-energy replies.
- 别问了: “别问 / 问就是快了” for deadline dodging.
- 问题不大: “问题不大 / 只是很大” for ironic calm.
- 我退一下: “我先 / 精神退场” for wanting to leave.
- 笑不出来: “笑不出来 / 但礼貌” for fake smiling.
- 稳住: “稳住 / 先别崩” for mutual support.
- 离谱: “有点 / 离谱了” for shock.

## Selection Rules

- A good sticker can answer a message by itself.
- The caption should be short enough to read in a chat bubble preview.
- The joke must survive outside the creator’s private context.
- Use verbs and situations, not abstract mood labels.
- Avoid rare slang that will age quickly unless the user explicitly wants a trend pack.

## Quality Bar

Before final delivery, ask of each GIF: “Would someone actually send this twice in a month?” If not, rewrite it or remove it.

Weak: “开心”, “难过”, “加油”.

Better: “我先装懂一下”, “问题不大只是很大”, “返修意见比正文长”.
